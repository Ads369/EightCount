# Проблема
Проблема ручного учёта:
Нет контроля баланса - непонятно кто и когда, сколько должен заплатить 
Ошибки списания - могут дважды списать или недобрать сумму 
Сложный отчёт в конце месяца - всё сводится к ручному труду, легко ошибиться 

## UseCase:
1. Человек приходит
2. Администратор прожимает кнопку "Пришёл"
3. Проверяет есть ли у пользователя деньги на счету 
4. Если есть - списывает 
5. Записывает дату и время
6. Сиестема должна показать "Успешно" или "Недостаточно средств"
